# ProjectTrack Server Windows Package

This folder is a self-contained Windows application image.

1. Double-click `ProjectTrack Server.exe`.
2. No Java/JDK installation is required to run the packaged server.
3. Keep the server running while clients use the system.
4. Allow TCP port 5050 through Windows Firewall when prompted.
5. The shared data is stored in the `data` folder used by the application.

The `runtime` folder contains the bundled Java runtime used by the executable.
Do not delete or rename it.
