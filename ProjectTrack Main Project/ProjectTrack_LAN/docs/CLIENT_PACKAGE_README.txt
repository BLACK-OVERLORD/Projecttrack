# ProjectTrack Client Windows Package

This folder is a self-contained Windows application image.

1. Double-click `ProjectTrack Client.exe`.
2. No Java/JDK installation is required on the client PC.
3. Enter the LAN IP address of the ProjectTrack Server PC.
4. Use TCP port 5050 unless the project configuration has been changed.
5. Log in using a server-side account.

The `runtime` folder contains the bundled Java runtime used by the executable.
Do not delete or rename it.
